# CS-193-Final-Project---RPG-Fitness-App

Project Goal: Create a gamified fitness app made to help people get excited about fitness through a combined RPG quest line, boss challenges, and character customization.

MVP Scope: 

When user first logs in their experience is evaluated first and then app generates a tailored workout weekly and yearly roadmap after taking in what their goals are as well
“Quest” Progress meter connected with RPG
Manual input of how many reps of each exercise, etc. that are then tracked
Character Screen with character profile and stats, (dungeon themed?)
Setting with story along with background art
Get perk points from increasing upper body, lower body, etc to level up fictional skills and craft potions etc.


Future Plans: 

If a workout plan is missed, update the workout plan, maybe penalize the user. Update the workout plan.
Post-workout feedback: ask the user how the workout felt and the overall difficulty of it as well as if they were able to complete all exercises
A skill spike graph:
- Upper Body
- Lower Body
- Endurance
- Consistency
- Core
- Mobility
Pre and Post gym interface vs minimal interface when working out interface that can be triggered by a timer or by simply pressing on a button to be taken to a non-game-like interface with:
- Timer
- Note like features that then translate to the actual game
RPG game features:
- Character customization:
- Include different races with upgrades and specific stories
- Being able to recruit someone and have them follow you
- Set weapons, equippables
